## `pr_readiness`

Decide whether a GitHub pull request is ready to merge, from live GitHub data. Call it before telling anyone a PR is ready, green or done.

Returns a verdict (ready / not_ready / merged / closed), the head sha the verdict is for, every blocking reason with a machine code and a fix, and the raw facts (draft, mergeable, review decision, checks by conclusion with failing and pending names, unsigned commits, requested reviewers, PR body lint hits).

A PR is not_ready when it is a draft, conflicts with its base, has failing or still-running checks, has commits without a verified signature, has body lint hits, or its checks are not for the current head. Review approval is reported in facts but does not block.

Pass expected_head_sha after a push so the verdict cannot describe an older commit.

Example: {"pr": "octo-org/widgets#42", "expected_head_sha": "4f1c2e7"}

Annotations: `readOnlyHint: true`, `idempotentHint: true`, `openWorldHint: true`

### Input schema

```json
{
  "type": "object",
  "properties": {
    "pr": {
      "type": "string",
      "description": "The pull request: a URL (\"https://github.com/octo-org/widgets/pull/42\"), \"octo-org/widgets#42\" or \"octo-org/widgets/42\"."
    },
    "expected_head_sha": {
      "description": "The commit you expect at the PR head, e.g. the output of `git rev-parse HEAD` after your last push. When the PR head differs, the verdict is not_ready with reason stale_head.",
      "type": "string",
      "pattern": "^[0-9a-f]{7,40}$"
    },
    "require_linked_issue": {
      "default": false,
      "description": "Set true when the repository requires every PR to reference an issue (e.g. \"Closes #12\").",
      "type": "boolean"
    },
    "ignore_rules": {
      "default": [],
      "description": "Lint rules to skip.",
      "type": "array",
      "items": {
        "type": "string",
        "enum": [
          "empty_body",
          "unchecked_box",
          "todo_marker",
          "missing_linked_issue"
        ]
      }
    }
  },
  "required": [
    "pr"
  ],
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## `pr_body_lint`

Check a pull request description for problems a reviewer would bounce: empty body, unchecked task boxes ("- [ ]"), TODO/FIXME/TBD/XXX markers, and (with require_linked_issue) no linked issue. Text in HTML comments and code is ignored.

Lint a published PR with pr, or a draft body before publishing with body. Each hit has a rule, a line number and a fix.

Examples: {"pr": "https://github.com/octo-org/widgets/pull/42"} or {"body": "Adds retries.\n\n- [ ] update docs", "require_linked_issue": true}

Annotations: `readOnlyHint: true`, `idempotentHint: true`, `openWorldHint: true`

{
  "type": "object",

      "description": "The pull request: a URL (\"https://github.com/octo-org/widgets/pull/42\"), \"octo-org/widgets#42\" or \"octo-org/widgets/42\". Give this or body.",
      "type": "string"
    },
    "body": {
      "description": "A PR body to lint before publishing it. Give this or pr.",
      "type": "string"

      "default": false,

      "type": "boolean"

      "default": [],

      "type": "array",
